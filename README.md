# À mon rythme

[Ouvrir le site](https://nh1980mg.github.io/a-mon-rythme/)

Objectifs, habitudes et calendrier personnel, sans compte requis. Les données restent dans le navigateur de chaque personne. La connexion Google/Discord n’est pas encore intégrée.

Ouvre **index.html** par double-clic dans ton navigateur (Safari, Firefox, Chrome ou Edge). Aucun serveur, compte ou téléchargement supplémentaire n'est nécessaire. Si le fichier est déjà ouvert, recharge l'onglet pour afficher cette version.

## Objectifs et dates

Un objectif peut contenir seulement un nom. Tu peux ajouter un groupe coloré, plusieurs étiquettes et, séparément :

- **Horizon** : la date à laquelle tu aimerais atteindre l'objectif ; sans date, il reste à long terme.
- **Période de travail** : une seule plage continue et facultative, par exemple tout un mois.
- **Séances** : les moments concrets où tu y travailles, répartis dans cette période si elle est définie.

Le bouton **Choisir une période**, au-dessus de la liste, permet de choisir un objectif, puis ses jours dans le calendrier. Le reste de l'interface s'assombrit pendant la sélection. Sur ordinateur, clique et glisse pour dessiner un rectangle ; tous les jours entre la première et la dernière date sont inclus. Sur mobile, touche le début puis la fin. Deux clics fonctionnent aussi à la souris et au clavier. Utilise **Valider** pour enregistrer, **Annuler** ou Échap pour revenir sans modifier les données. La navigation entre mois permet une plage longue.

Dans la création ou la modification d'un objectif, tu peux saisir les deux dates directement ou passer par le calendrier. Le brouillon du formulaire est conservé pendant ce passage.

## Séances

Le bouton **Séances** d'un objectif affiche le nombre déjà placé dans le calendrier. Il n'y a aucun nombre de séances à prévoir à l'avance. Son menu propose un bloc réutilisable **Nouvelle séance** : glisse-le sur un jour, puis confirme l'heure et la durée. Le bouton **Planifier** fournit la même action au clavier et sur mobile.

Chaque nouvelle séance validée augmente le compteur des séances placées. La case à cocher d'une séance l'indique comme effectuée. Le menu affiche par exemple **5 placées · 2 effectuées** : les effectuées sont incluses dans les placées. Déplacer une séance ne change pas ces compteurs ; la retirer du calendrier les met à jour.

Une séance peut être modifiée ou déplacée dans le calendrier. Avec une période de travail définie, sa date doit rester à l'intérieur. Une modification de période qui exclurait des séances existantes est refusée avec leur liste : déplace ces séances, retire-les ou élargis la période. Cocher l'objectif et cocher une séance sont deux actions indépendantes.

Pour ajouter ou modifier une **description**, clique directement sur la séance dans le calendrier. Le formulaire contient un champ de notes de 5 000 caractères : étapes, ressources, résultats ou explications. Le contenu est conservé avec la séance et dans les sauvegardes. Un petit signe ✎ dans le calendrier indique qu'une description est présente.

## Groupes d'habitudes et motifs

L'onglet **Habitudes** permet de créer des groupes de créneaux récurrents ou exceptionnels, indépendants des objectifs. Les occurrences apparaissent dans le même calendrier que les séances ponctuelles.

1. Crée un groupe, donne-lui un nom et une couleur, puis choisis le **premier jour du premier motif**.
2. Choisis le **nombre de jours du motif** : par exemple 7 jours pour une semaine.
3. Choisis **Répétitif** et un intervalle en jours ou semaines, ou **Exceptionnel** pour n'appliquer le motif qu'une fois. Une date de fin est facultative.
4. Ajoute les créneaux du groupe : jour dans le motif, heure précise, durée et description facultative. Le menu montre les jours de semaine et dates du premier cycle comme exemple.

Exemple : pour travailler le japonais chaque lundi à 18 h, choisis un début de motif un lundi, 7 jours dans le motif, une répétition toutes les semaines et un créneau au Jour 1 à 18 h. Pour une semaine sur deux, conserve le motif de 7 jours et répète tous les 14 jours ou toutes les 2 semaines. Un motif de 5 jours répété tous les 7 jours permet de ne couvrir que la semaine de travail. L'intervalle doit être au moins égal à la longueur du motif ; si l'intervalle n'est pas un multiple de 7, les jours de semaine peuvent changer d'un cycle à l'autre.

Les habitudes sont signalées par **↻** dans le calendrier. Clique sur une occurrence pour modifier uniquement cette date, ses notes, son heure, sa réalisation ou son annulation. Tu peux également la déplacer vers un autre jour par glisser-déposer. Les occurrences suivantes continuent de suivre le motif. Une case à cocher est disponible dans l'agenda du jour.

Les occurrences personnalisées se retrouvent dans le détail du groupe. **Rétablir** retire la personnalisation, y compris sa coche, et réapplique le motif. Les groupes avec des occurrences personnalisées protègent leur ancrage, leur cadence et les jours des créneaux concernés : rétablis les occurrences ou crée un autre groupe pour changer ce rythme. Changer un titre ou ajouter un créneau reste possible tant que les personnalisations existantes demeurent valides.

Le calendrier calcule les occurrences à afficher sans préremplir une infinité de séances. Les habitudes et leurs personnalisations sont conservées dans les sauvegardes ; les anciens fichiers restent importables. Les compteurs d'un objectif continuent de concerner ses propres séances, séparément des groupes d'habitudes. Il n'y a pas de notification système automatique.

## Composer les horaires et les lignes de séparation

Dans **Groupes**, choisis un groupe d’habitudes ou crée-le dans la petite fenêtre. Son éditeur affiche à gauche exactement les jours du motif : une colonne pour un jour, trois pour trois jours. Les groupes d’objectifs restent disponibles séparément, plus bas dans le même onglet. L’onglet **Habitudes** donne aussi accès au bouton **Composer les horaires**.

Les blocs à droite servent à préparer une habitude avec sa durée, ou une **ligne de séparation** sans durée, par exemple « Fin du déjeuner — 13 h ». Configure le bloc, glisse-le vers un jour et une heure, puis valide. **Placer · choisir les jours et l’heure** permet la même chose au clavier ou sur mobile. Le mode **Placer sur plusieurs jours** reste activé : maintiens et parcours les jours voulus, vérifie l’heure puis valide ; **Terminer** ou Échap quitte ce mode.

Les lignes restent déplaçables après enregistrement et réouverture. Maintiens une ligne et déplace-la : son heure s’affiche pendant le geste, par pas de cinq minutes ; relâche pour enregistrer. Un clic ouvre sa modification à la minute près. Déplacer une ligne ne déplace pas les séances. Dans l’éditeur, tu modifies le motif ; dans le calendrier général, tu modifies seulement l’occurrence choisie.

Le calendrier général propose **Mois**, **Semaine** et **Jour**. Semaine et Jour montrent une grille horaire ; Mois présente des repères compacts avec l’heure des lignes. Les motifs longs et les semaines peuvent défiler horizontalement sur petit écran.

Un **clic droit**, ou le bouton **⋯** d’un jour, ouvre les actions : ajouter une ligne, ajouter une séance d’un objectif, ou annuler les créneaux d’un groupe pour le jour ou la semaine. Sur un créneau, le menu propose sa modification et son annulation ; sur une ligne, son extension à toute la semaine, plusieurs semaines ou un nombre de jours consécutifs, avec un aperçu des dates (366 jours maximum). Les copies restent indépendantes.

Une annulation de groupe affiche les dates et le nombre de créneaux concernés avant validation. Le motif et les autres semaines sont conservés. Les occurrences d’habitudes annulées sont rétablissables dans les personnalisations du groupe ; une séance d’objectif annulée reste dans son menu **Séances**, avec **Rétablir**. Les compteurs actifs excluent les séances annulées. Le rétablissement vérifie que la séance entre toujours dans la période de travail de l’objectif.

## Historique et bilans

Cocher un objectif terminé l'ajoute à l'onglet **Historique** et libère son éventuelle place parmi les trois priorités. Une fenêtre propose un bilan, que tu peux renseigner maintenant ou plus tard :

- Accomplissement : **20, 25, 50, 75 ou 100 %**.
- Conformité du résultat : **Conforme à ce que je voulais**, **Plutôt conforme**, **Peu conforme**, **Pas du tout conforme**.

Ces deux mesures sont indépendantes. Le bouton **Modifier le bilan** reste disponible dans l'historique. **Reprendre** remet l'objectif dans les objectifs actifs, sans supprimer ses séances. Les objectifs déjà terminés dans une ancienne sauvegarde restent accessibles, avec un bilan et une date non renseignés plutôt qu'inventés. Les terminés sont masqués par défaut dans la liste active, et peuvent aussi y être affichés avec la case prévue.

## Études et techniques

L'onglet **Études & techniques** contient les dix références discutées : déclencheurs si-alors, suivi des progrès, WOOP, changements de tâche, notifications, pauses, rappel de mémoire, espacement, entrelacement et auto-explication.

Chaque fiche donne le résultat, une limite, un lien vers la publication et une application concrète dans À mon rythme. Les badges distinguent l'appui disponible dans l'outil, les pratiques à réaliser soi-même et les actions à effectuer hors du site. L'application ne prétend pas être scientifiquement validée et n'ajoute pas automatiquement de quiz, rappels ou algorithme de répétition espacée.

Le HTML **ne peut pas couper les notifications des autres applications**. Active « Ne pas déranger » dans le système. Une application native peut disposer de possibilités supplémentaires selon la plateforme et les permissions : les documentations web et Android sont liées dans ce panneau.

## Organisation et apparence

- Les étoiles sélectionnent jusqu'à trois objectifs prioritaires.
- Le menu **Classer par** affiche les cartes par groupe, date d'horizon ou étiquette.
- Les onglets **Étiquettes** et **Groupes** permettent de les gérer.
- Les boutons **Doux** et **Coloré** changent l'ambiance. Le thème Coloré transforme presque toute l'interface (fond, en-tête, navigation, calendrier, priorités, menus et formulaires), avec un fond de page blanc et une palette bleu profond, crème et jaune vif pour les éléments de l’interface. Les couleurs des groupes d'objectifs restent libres ; le choix de thème est enregistré.
- Le bouton **?** ouvre le mode d'emploi dans l'application.

## Sauvegarde et mise à jour

Les données sont enregistrées dans le stockage local du navigateur. Garde le fichier au même emplacement et utilise le même navigateur pour les retrouver. La navigation privée, la suppression des données du navigateur ou le déplacement du fichier peuvent rendre cette sauvegarde inaccessible. **Exporte une copie JSON régulièrement** avec le bouton en haut à droite ; l'autre bouton permet de la réimporter.

La version précédente est migrée automatiquement : ses anciennes plages deviennent des périodes de travail, les nouveaux horizons restent à long terme et les séances sont conservées. Une copie du format précédent est gardée dans le stockage local avant remplacement. Les anciens modèles sont accessibles dans le menu Séances. Les anciennes séances hors période restent visibles et signalées, sans déplacement ni suppression automatique.

Si le stockage local est bloqué, l'application permet de travailler en mémoire et d'exporter les données ; un avertissement indique qu'elles ne sont pas sauvegardées entre les ouvertures.
